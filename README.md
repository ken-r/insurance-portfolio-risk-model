# Insurance Portfolio Risk Model

I am interested in how insurance portfolios are modeled and how their risks are measured. In this project, we simulate portfolio losses, then analyze and plot the results.

## Setup

The project requires Python 3.11 or newer.

From the project root, create and activate a virtual environment:

```bash
python -m venv .venv
.\.venv\Scripts\Activate
```

Then install the project in editable mode:

```bash
pip install -e .
```

## Run

Run the simulation from the same directory:

```bash
python run_simulation.py
```

Outputs are saved to the `output` directory.
